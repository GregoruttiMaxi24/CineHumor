## 🇺🇸 English

### 📖 About the Project

**CineHumor** is a web application developed as an academic project for managing and exploring a movie catalog.

The application was built using **PHP, MySQL and Object-Oriented Programming (OOP)**, following an **MVC architecture** to separate the application's logic, data and presentation layers.

The project focuses on applying backend and web development concepts such as database management, authentication, CRUD operations, sessions and relationships between different entities.

### 🚀 Features

* 🎬 Movie catalog and detailed movie information
* 🔎 Movie search and filtering
* 🎭 Management of actors, directors and screenwriters
* 🎨 Movie classification by genres and moods
* 🤖 Movie recommendation system
* 🔐 User registration, authentication and session management
* 👤 User roles and access control
* ⚙️ Administration panel
* 📝 CRUD operations for movies and related entities
* 💾 MySQL database using PDO
* 🔗 Relationships between movies, genres, actors and other entities
* 📷 Image management for movie records

### 🛠️ Technologies

* **PHP**
* **MySQL**
* **PDO**
* **Object-Oriented Programming (OOP)**
* **MVC Architecture**
* **HTML5**
* **CSS3**
* **Bootstrap**
* **JavaScript**

### 🏗️ Architecture

The project follows an **MVC (Model-View-Controller)** architecture, separating the application's main responsibilities:

```text
CineHumor/
├── controllers/
├── models/
├── views/
├── index.php
├── autoload.php
└── ...
```

This structure helps keep the application organized and makes the code easier to maintain and extend.

### 🎯 Project Objective

The main objective of CineHumor was to put into practice backend and web development concepts using **PHP and MySQL**, including Object-Oriented Programming, MVC architecture, database relationships, authentication, CRUD operations and session management.

This project was developed as part of my **Web Design and Development studies**.

## 🇦🇷 Español

### 📖 Sobre el proyecto

**CineHumor** es una aplicación web desarrollada como proyecto académico para la gestión y exploración de un catálogo de películas.

La aplicación fue desarrollada utilizando **PHP, MySQL y Programación Orientada a Objetos (POO)**, siguiendo una **arquitectura MVC** para separar la lógica, los datos y la presentación de la aplicación.

El proyecto busca aplicar conceptos de desarrollo backend y web como gestión de bases de datos, autenticación, operaciones CRUD, manejo de sesiones y relaciones entre diferentes entidades.

### 🚀 Funcionalidades

* 🎬 Catálogo de películas con información detallada
* 🔎 Búsqueda y filtrado de películas
* 🎭 Gestión de actores, directores y guionistas
* 🎨 Clasificación de películas por géneros y estados de ánimo
* 🤖 Sistema de recomendación de películas
* 🔐 Registro, autenticación y manejo de sesiones
* 👤 Roles de usuario y control de acceso
* ⚙️ Panel de administración
* 📝 Operaciones CRUD para películas y entidades relacionadas
* 💾 Base de datos MySQL mediante PDO
* 🔗 Relaciones entre películas, géneros, actores y otras entidades
* 📷 Gestión de imágenes de las películas
